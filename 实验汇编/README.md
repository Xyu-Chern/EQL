## 跨章比较口径

- **第 01 与 02 章**使用不同训练骨架、更新预算和超参。四组初测回答实现问题，三方法基线回答原配置下的回报问题。
- **第 03 与 04 章**分别使用搜索 seeds 101–102、复测 seeds 201–204。各方法搜索次数相同，但 SAC 搜学习率，EQL 搜 τ。
- **第 06、08、09 章**的 Pendulum 对照可按同一个 seed 查询。第 08、09 章固定 τ_Q=0.1、τ_a=0.7；第 06 章的九组包含这个配置。
- **回报与误差指标**分别回答策略表现和价值估计质量。最后一章的相关性在相同的 336 个状态动作上计算，每个模型以自己的冻结策略估计参考软 Q。
