# Teacher replay-buffer implementation

This implements the rectangular `num_envs x num_steps` fragment interpretation of the whiteboard.
It does **not** claim persistent full-episode bootstrap masks: an episode crossing collection blocks can reach different bags.
An 8-step fragment can contain an environment reset; each transition preserves its own pre-reset next observation and terminal semantics.

## Buffer contract

- `BagReplayBuffer.empty(example, num_critics, capacity)` creates `[critics, capacity, ...]` leaves.
- `add(fragments, rng, num_duplicates=d)` assigns each entire `[num_steps,...]` fragment to d DISTINCT critics.
- Requires `num_envs*d % num_critics == 0`, a stronger whole-fragment requirement than transition divisibility.
- Random permutation of environment order and critic order each add avoids fixed env/critic binding. All bags receive exactly the same number of fragments.
- Default is circular replay. `replace=True` resets the visible count to the new block, covering the whiteboard replacement example.
- `sample(rng, per_bag_batch_size)` returns `[critics, batch, ...]`, with independent keys and sampling with replacement. Check `ready()` before sampling an empty bag.
- Actor uses `GlobalReplayBuffer` of original transitions, not a duplicate-weighted bag union.
- For matched history windows, per-bag capacity = global capacity*d/critics; experimental capacities are exact collection-block multiples.

## Algorithm and four controls

`BagEQL` in `online_bag_eql.py` reuses Rejax SAC networks, optimizers and temperature update.

| Group | data_mode | target_mode |
|---|---|---|
| A | shared | shared |
| B | bag | shared |
| C | shared | own |
| D | bag | own |

Both modes use independent per-critic minibatches with the same per-critic batch size.
Shared targets evaluate the entire target ensemble at each critic's batch queries; own targets only evaluate that critic's target network.
Actor aggregation, entropy, temperature tuning, target Polyak update and training budget are held fixed.
Neither own targets nor disjoint bags imply complete statistical independence of networks sharing an actor/environment.

## Deliberate corrections relative to original eql.py

- `tau_actor` explicitly denotes critic-axis aggregation for actor updates. No action-axis expectile is tested here.
- Exact sorted expectile forward with a local custom JVP replaces finite IRLS with epsilon-biased denominator. At ties the autodiff convention is not a claim of ordinary differentiability.
- For Gymnax Pendulum/Reacher, time limits bootstrap from pre-reset observations. `step_env` plus explicit reset prevents bootstrapping from the next episode.
- Warmup actions are uniform random. Normalize observation/reward options are not used by this experimental runner.
- Each rollout collects envs*steps transitions. Custom train loop avoids Rejax's one-step-loop overcounting.
- Per-critic losses are averaged over that critic's batch then summed across critics, preserving each critic's gradient scale.
- All four groups share these corrections. Old repository plots are not directly comparable to these new runs.
